CSR Screening Tool
About

From Phase I observations to screening thresholds in one workflow.

A user friendly screening tool connecting land use, contaminants of concern, lab data, and BC CSR Schedule 3.1 thresholds.

Image credit: “Phase 1 ESA” by ESESIS Environmental, CC BY-NC 4.0.

How it works

  1. Select land use Residential, commercial, or industrial
  2. Choose contaminants Pick from roughly 40 chemical compounds
  3. Enter lab data Input your measured concentrations
  4. View results See if thresholds are exceeded

BC CSR Screening Tool — Educational use only. Not professional advice.
